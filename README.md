# Personal Branding OS — v1.0

> **「疲弊せず、持続可能に5つの資本を同時前進させる個人経営体制」**

---

## このシステムとは

私（24歳・監査法人トーマツ勤務・USCPA合格）を1つの会社として見立て、
仕事・学習・健康・財務・ブランドを同時に前進させるための
AI支援型の個人経営OSです。

単なるタスク管理ではなく、**私という人間の価値を中長期で高める経営基盤**として設計されています。

## 5つの資本

このOSは以下の5資本を同時前進させることを目的としています。

```
信用資本 ──── 監査実績 × ブランド発信
知的資本 ──── CIA取得 × 継続学習
健康資本 ──── ジム定着 × 睡眠改善
財務資本 ──── 投資継続 × 独立資金形成
社会資本 ──── 信頼ネットワーク形成
```

## 運用ルール（3行サマリー）

1. **毎朝3分** — `00_DASHBOARD.md` を見て今日の3優先事項を確認
2. **毎週1回** — `reviews/05_WEEKLY_REVIEW_TEMPLATE.md` でレビュー（20〜30分）
3. **毎月1回** — `reviews/06_MONTHLY_REVIEW_TEMPLATE.md` で月次振り返り（45〜60分）
