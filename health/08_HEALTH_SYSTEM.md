# 08 HEALTH SYSTEM — 健康・習慣管理システム

> 「理想論ではなく、監査法人勤務でも回る現実的な健康設計」
> 完璧を目指さず、ゼロにしないことを最優先とする。

---

## 1. 健康の全体方針

### 目指す姿（長期ビジョン）
- ジムに週3回通う習慣が定着している
- 将来的には大会に出られるレベルの体型を目指す
- 歯列矯正が計画通りに進んでいる
- 睡眠が安定していて、疲弊しない体力がある

### 今の現実（事実）
- ジム契約済み・しかし仕事の疲弊でなかなか行けない
- マウスピース：就寝時着用必要 → 着けられていないことが多い
- 睡眠：繁忙期に削られがち
- 体重72kg・身長178.9cm（BMI約22.5：標準範囲内）

### 設計原則
1. **ゼロにしない** — 完璧な週より、最小でも続く週を優先
2. **最小行動を設定** — 疲れ果てていても「これだけはできる」を持つ
3. **段階設計** — いきなり週3ではなく、週1→週2→週3と段階を踏む
4. **健康とブランドを接続** — 「身体を作る自己規律」はブランド価値になる

## 2. ジム通い定着システム

### 段階設計

| フェーズ | 目標頻度 | 期間目安 | 条件 |
|---------|---------|---------|------|
| Phase 0（現在） | 週1回 | 4〜8週間 | 1回でも行けたら成功 |
| Phase 1 | 週2回 | 4〜8週間 | 週1が安定したら移行 |
| Phase 2 | 週3回 | 継続 | 最終目標 |
| Phase 3（将来） | 週3回 + 大会準備 | 1〜2年後 | 習慣が完全定着後 |

**繁忙期（期末監査）は1フェーズ下げてOK。**
→ Phase 2中でも、繁忙期はPhase 1基準に下げる。ゼロにしない。

### 「行けない」を減らす工夫

| 障壁 | 対策 |
|------|------|
| 疲れて気力がない | 「着替えるだけ」をゴールにする。着替えたら行く |
| 仕事が長引く | 翌朝ジムの時間をカレンダーに入れる |
| 準備が面倒 | ジムバッグを玄関に常備。前日夜に用意 |
| やる気が出ない | 「30分だけ」と決める。伸ばしてもよい |
| 帰りに寄れない | 朝型に切り替えを検討（仮説：朝の方が継続しやすい） |

### 最小行動（省エネモード時）
- **最低限：** 着替えてジムに行く → 有酸素10分で帰ってもOK
- **ゼロの代替：** 自宅での体重スクワット20回 × 3セット（15分）
- **完全ゼロの日：** ストレッチ5分だけでもOK

## 4. 睡眠管理

### 目標
- 平日：7時間（最低6時間）
- 休日：7〜8時間

### 睡眠を守るためのルール
1. **23時就寝 / 6時起床** を基本設定とする（仮説：通勤時間考慮）
2. 繁忙期でも**24時就寝** を死守ラインとする
3. **スマホ使用は就寝30分前まで**（難しければ15分前でも可）
4. 睡眠不足の翌日は**省エネモード**に自動切替

### 睡眠不足サイン
以下が3日続く場合は、COO Agentにスケジュール見直しを依頼すること：
- 起床時に疲れが抜けていない
- 昼間に眠気が激しい
- 仕事へのモチベーションが著しく低下

## 5. 疲弊防止の設計

### 疲弊レベル判定

| レベル | 状態 | 対応 |
|-------|------|------|
| 0（普通） | 普通に動ける | 通常モード |
| 1（疲れ気味） | やや疲れているが機能する | 省エネモード |
| 2（かなり疲弊） | 集中困難・意欲低下 | 最小行動のみ + 回復優先 |
| 3（限界） | 体に症状が出ている | 休息を最優先・仕事も最低限に |

### 繁忙期（期末監査：2〜3月・8〜9月）設計
- ジム：週1でもOK（Phase 0基準）
- マウスピース：「歯磨き後に置く」だけでもOK（着けなくても可）
- 学習（CIA等）：完全停止してOK
- 睡眠：24時就寝死守
- 健康維持の最低ライン：**食事・睡眠・歩く（通勤）**

## 6. 身体づくりとブランドの接続

### 体型改善がブランドになる理由
- 「規律ある生活を送っている」という信頼感を与える
- 写真・プロフィールの見た目が向上する
- 自己信頼感が仕事のパフォーマンスにも影響する

### 現在の目標体型（仮説）
- 体脂肪率：15%以下（現在未計測 → 計測推奨）
- 筋肉量：現状維持 → 増量フェーズは Phase 2 以降
- 優先部位：全身バランス（大会出場を視野に入れる場合は後で戦略化）
