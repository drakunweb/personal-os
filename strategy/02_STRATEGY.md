# 02 STRATEGY — 中長期戦略

> 私の人生・キャリア・ブランドの方向性を定める戦略ドキュメント。
> 四半期に1回の見直しを推奨。

---

## 1. 北極星（North Star）

> **24歳の今から、規律ある生活と積み重ねを通じて、
> 35歳までに「信用・知性・健康・財務」の4資本を高め、
> 自分が選んだ働き方で生きられる状態になる。**

## 2. 時間軸別戦略

### 短期（〜1年：2026〜2027）
**テーマ：「疲弊せず、土台を作る」**

| 領域 | 目標 |
|------|------|
| 仕事 | 期末監査を疲弊せず乗り越え、具体的な実績を作る |
| 健康 | ジム週1→週2の定着・マウスピース治療の前進 |
| 財務 | 緊急予備費の目標額確立・投資積立継続 |
| キャリア | CIA学習の着手（繁忙期以外） |
| ブランド | 自分のポジショニング仮説を検証する |

**捨てること（短期）：**
- 発信活動の大規模展開（今は準備期間）
- CIA以外の資格の追加検討
- 副業・収入多角化の具体化

### 中期（1〜3年：2027〜2029）
**テーマ：「資産を積み上げる」**

| 領域 | 目標 |
|------|------|
| 仕事 | 社内評価の向上・専門性の明確化 |
| 健康 | ジム週3定着・理想体型への前進 |
| 財務 | 独立準備資金の積み上げ開始 |
| キャリア | CIA取得・次の資格検討 |
| ブランド | 発信活動の本格開始・信用資産の構築 |

**捨てること（中期）：**
- 見切り発車の独立
- ブランドテーマの頻繁な変更

### 長期（3〜10年：2029〜2036）
**テーマ：「選択肢を行使する」**

| 領域 | 目標 |
|------|------|
| 仕事 | 独立 or 現職でのプレゼンス向上の判断・実行 |
| 健康 | 大会出場可能なレベルの体型維持 |
| 財務 | 資産形成の加速・財務的独立への前進 |
| ブランド | 独自ポジションの確立 |

## 4. キャリア戦略

### 基本方針
**現職最優先 × 独立オプションを育てる**

- 監査法人での実績を着実に積む
- 資格（CIA・他）で専門性を強化する
- 発信・ネットワーキングで長期的な信用を構築する
- 独立は「決めること」ではなく「選択できる状態を作ること」

### 資格ロードマップ（仮説）

| 資格 | 優先度 | 時期（仮説） | 理由 |
|------|--------|------------|------|
| CIA | ★★★ | 2026〜2027 | 内部統制の専門性強化・独立でも使える |
| CISA | ★★ | 2027〜2028 | ITと監査の掛け合わせ |
| 日本語の会計系資格 | ★ | 未定 | 市場ニーズを確認してから |

## 5. 戦略的意思決定フレームワーク

大きな意思決定（転職・独立・資格追加・住居変更など）の際は、
以下の質問に答えてから判断する：

1. **これは5つの資本を前進させるか？**（信用・知性・健康・財務・社会）
2. **疲弊せず続けられるか？**（80%の力でも回るか）
3. **捨てるものは何か？**（何かを足すなら何かを引く）
4. **最悪のシナリオは許容できるか？**
5. **3ヶ月後に振り返って正解と言えそうか？**

---

## 6. 戦略の更新ルール

- **四半期に1回：** 大きな変化があれば見直す
- **年次レビュー時：** 時間軸別戦略の進捗確認と修正
- **重大イベント時：** 転職・独立判断・ライフイベント
