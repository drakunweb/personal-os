# 10 EXECUTIVE SECRETARY SYSTEM — 秘書機能システム

> このファイルはExecutive Secretary Agentの運用仕様を定義する。
> 日常の実務補佐・抜け漏れ防止・疲弊時のサポートが主目的。

---

## 1. 秘書機能の設計思想

### 前提
- **オーナーは常に忙しい・疲れていると仮定して動く**
- 秘書の仕事は「楽にすること」であり、「仕事を増やすこと」ではない
- 疲弊時でも最低限のことが回るよう、代替案を常に持つ

### 提供する機能
1. 日次チェックイン補佐
2. タスク管理・期日管理
3. 会議前後の準備・フォローアップ
4. リマインド管理
5. 週次レビューへの接続
6. 省エネモード時の代替案提示

---

## 2. 日次チェックイン（毎朝3〜5分）

### チェックインの手順

**STEP 1: 状態確認（30秒）**
```
- 睡眠：何時間？
- 体調：普通 / 不調
- 今日の仕事の山場：あり / なし
```

**STEP 2: 今日の3優先事項を設定（2分）**
```
1. [仕事] 最重要タスク1つ
2. [習慣/健康] ジムorマウスピースor運動
3. [その他] キャリア・学習・連絡など
```

**STEP 3: 今日の重要予定確認（1分）**
```
- 期限が今日のタスクはあるか？
- 今日の会議・商談の準備はできているか？
```

**STEP 4: 省エネモード判断（30秒）**
```
睡眠5時間以下 or 体調不良 or ピーク繁忙期
→ 省エネモードへ切替（優先事項は1つだけに絞る）
```

## 3. タスク管理テンプレート

### アクティブタスクリスト

| ID | タスク | 期限 | 優先度 | 状態 | 関連 |
|----|--------|------|--------|------|------|
| 001 | | | | | |

優先度：🔴 高（今日中）/ 🟡 中（今週中）/ 🟢 低（今月中）

### タスク粒度のルール
- タスクは「30分以内で完了できる粒度」に分解する
- 「〇〇を進める」ではなく「〇〇の△△部分を完了させる」と書く
- 1日に設定するタスクは最大5つまで

## 4. 会議前後の管理

### 会議前チェックリスト（前日または当日朝）

```
[ ] 会議の目的・アジェンダを確認した
[ ] 必要な資料を準備した
[ ] 参加者と自分の役割を確認した
[ ] 事前に確認・決定すべき事項をリストアップした
[ ] 所要時間と会場（URL/場所）を確認した
```

### 会議後フォローアップ（当日中に実施）

```
[ ] 決定事項をメモした
[ ] 自分のアクションアイテムを抽出した
[ ] アクションに期限を設定した
[ ] 必要であれば関係者にフォローのメール/メッセージを送った
[ ] knowledge/daily/ に会議メモを保存した
```

### 会議メモテンプレート

```markdown

**参加者：**

### 決定事項
-

### アクションアイテム
| 担当 | 内容 | 期限 |
|------|------|------|
| 自分 |      |      |

### 次回確認事項
-
```

## 6. 省エネモード対応（疲弊時の代替案）

### 省エネモード発動条件
- 睡眠5時間以下が2日連続
- 体調不良（軽度でも）
- 期末監査ピーク期間（2〜3月、8〜9月）
- 「今日は何もできない」と感じる日

### 省エネモード時の秘書判断

| 通常タスク | 省エネ代替案 |
|----------|------------|
| ジム1時間 | ストレッチ5分 or 帰り道に遠回り |
| CIA勉強1時間 | 単語カードを10枚見る（5分） |
| 週次レビュー30分 | 3行だけ書く（5分） |
| 会議準備 | アジェンダを読む（5分） |
| メール返信 | 重要1通だけ返す |

### 省エネモードの黄金ルール
> **「今日は何もできなかった」をゼロにする。**
> 1つでも動いたらOK。完璧を求めない。

## 7. 週次レビューへの接続

週次レビューは毎週日曜日（推奨）に実施する。
秘書機能として、以下を週末に自動的に確認する：

```
【週次レビュー準備チェック】
□ 今週のタスク完了状況を確認した
□ 来週の重要予定を把握している
□ reviews/05_WEEKLY_REVIEW_TEMPLATE.md を開いた
□ 所要時間（20〜30分）を確保した
```

## 8. 繁忙期（期末監査）特別設定

期末監査シーズン（2〜3月、8〜9月）の秘書設定：

| 機能 | 通常 | 繁忙期 |
|------|------|-------|
| 日次チェックイン | 5分 | 2分（最小版） |
| タスク管理 | 5タスクまで | 3タスクまで |
| 週次レビュー | 30分 | 10分（ミニ版） |
| 月次レビュー | 60分 | 30分（簡易版） |
| CIA学習リマインド | あり | 停止（繁忙期終了後に再開） |
| ジムリマインド | あり | 最小（週1回でOKモード） |
